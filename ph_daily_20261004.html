SCMD 精选 89
管理克劳德的记忆和保持的内容。
Claude专属！SCMD 是一个开源的本地审查工具，专为 Claude Code 保存的关于您和您项目的持久记忆而设计。您可以选择保留、删除、跳过、撤销、重写，或者查看记忆保存的原因。所有决策都会暂时保留，直到您确认；删除的内容会被移到可恢复的垃圾箱中。SCMD 不收集任何数据，也没有云服务和 npm 依赖项。您可以通过 /scmd:run 或 npx 来运行它。它采用 MIT 许可证，并欢迎贡献者参与。

eu/jev 精选 85
首个类似Jev的模型在欧盟推出
如果你想尝试像Jev这样的System One模型，但因为GDPR和数据主权问题而无法使用，eu/jev就是你的理想选择；这是第一个在欧盟内托管的System One模型，运行在我们位于德国的Hetzner GPU上。它完全符合GDPR规定，并且我们不会保存任何输入或输出内容。你可以像调用Jev一样调用它，价格与Jev完全相同（这意味着输出令牌是免费的！）。该模型基于Winnow，Winnow是JevBench上排名第一的开源System One模型。
